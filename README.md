# Student Management System

## Description
This is a web-based Student Management System developed using PHP and MySQL.  
It helps to manage student records with features like adding, viewing, editing, and deleting student details.

## Features
- Add Student Details
- View Student Records
- Update Student Information
- Delete Student Records
- User Login and Logout system

## Modules
- Login Page
- Dashboard
- Add Student
- View Student
- Edit Student
- Delete Student
- Register Page
- Logout

## Technologies Used
- PHP
- MySQL
- HTML
- CSS

## How to Run
1. Install XAMPP
2. Place project folder inside 'htdocs'
3. Start Apache and MySQL in XAMPP
4. Import database in phpMyAdmin
5. Open browser and go to:
   http://localhost/project1/

## Note
Make sure database connection is configured properly in connect.php file.
